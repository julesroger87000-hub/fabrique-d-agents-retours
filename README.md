# Retours sur La Fabrique d'Agents

Ce dépôt reçoit les leçons anonymes partagées par les membres de L'Atelier Fantôme avec la commande `/partager`.

**Tout ce qui est écrit ici est public, avec le pseudo GitHub de son auteur.** N'y mets jamais de nom de client, d'entreprise ou de personne, d'adresse, de chiffre d'activité, de mot de passe ni de clé.

Chaque leçon est relue, contrôlée et réécrite avant d'entrer dans la mémoire commune. Une leçon qui contient un lien, du code ou une commande est refusée.

En ouvrant un ticket, tu autorises le responsable de la Fabrique à réutiliser et adapter ta leçon.
